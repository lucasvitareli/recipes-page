# 🍝 Chef Navarro - Recipes Web App

Welcome to **Chef Navarro**, a personal recipe showcase web application built with **React**. This project simulates the website of a fictional Brazilian chef living in the U.S., aiming to share delicious recipes with an international audience.

## 📚 About the Project

This responsive web application allows users to:

- Browse a variety of recipe cards
- Search for recipes by name in real time
- View recipe details with ingredients and step-by-step instructions
- Discover more through a **membership area**
- Navigate the site with a responsive **hamburger menu**
- See restricted content alerts for non-members
- Experience smooth scroll navigation and modern UI

---

## ✨ Features

- ⚛️ Built with **React**
- 🎨  Styled with **Styled Components**
- 🔍 Real-time search filtering
- 🧾 Routing with **React Router**
- 🎥 Conditional access to video content for members
- 📱 Fully responsive layout
- 💬 Modal system for alerts and restricted content
- 🧭 Section-based smooth scrolling
- 🌈 Global theming with custom color and font variables
